# 🏢 SG3S — Sistema de Gerenciamento

Sistema web de gerenciamento comercial desenvolvido individualmente, do zero, como **Projeto Integrador (PI)** do curso técnico em **Análise e Desenvolvimento de Sistemas (ADS)**.

O SG3S foi desenvolvido com o objetivo de auxiliar no gerenciamento e controle de operações comerciais, oferecendo funcionalidades para administração de tecidos, usuários, fornecedores, clientes, relatórios e vendas.

A aplicação utiliza **PHP, JavaScript, HTML, CSS e MySQL**, seguindo o padrão arquitetural **MVC (Model-View-Controller)** e utilizando o framework **Bootstrap** para construção e estilização das interfaces.

O sistema possui módulos de gerenciamento com operações CRUD (Create, Read, Update e Delete), permitindo cadastrar, consultar, editar e excluir registros de acordo com as funcionalidades de cada módulo.

## 🏗️ Arquitetura do Sistema — MVC

O SG3S utiliza o padrão arquitetural **MVC (Model-View-Controller)**, que organiza a aplicação em três camadas principais:

### Model
Responsável pela interação com o banco de dados e pelo gerenciamento das informações da aplicação.

### View
Responsável pela apresentação das interfaces e pela interação visual com o usuário.

### Controller
Responsável por receber as requisições, controlar o fluxo da aplicação e conectar os modelos às visualizações.

A utilização desse padrão contribui para a organização do código, separação de responsabilidades e manutenção do sistema.
