# 🏢 SG3S — Sistema de Gerenciamento

Sistema web de gerenciamento desenvolvido como **Trabalho de Conclusão** do curso técnico em **Análise e Desenvolvimento de Sistemas (ADS)**.

O SG3S é uma aplicação web desenvolvida para auxiliar no gerenciamento e controle de operações comerciais, oferecendo funcionalidades para administração de tecidos, usuários, fornecedores, clientes, relatórios e vendas.

O sistema foi desenvolvido utilizando **PHP, JavaScript, HTML, CSS e MySQL**, seguindo o padrão arquitetural **MVC (Model-View-Controller)**, com interfaces estilizadas utilizando o framework Bootstrap.

A aplicação conta com operações CRUD (Create, Read, Update e Delete) nos módulos de gerenciamento, permitindo cadastrar, consultar, editar e excluir registros de acordo com as funcionalidades de cada módulo.

## 🏗️ Arquitetura do Sistema — MVC

O SG3S utiliza o padrão arquitetural **MVC (Model-View-Controller)**, que organiza a aplicação em três camadas principais:

- **Model:** Responsável pela interação com o banco de dados e pelas informações da aplicação.
- **View:** Responsável pela apresentação das interfaces e interação visual com o usuário.
- **Controller:** Responsável por receber as requisições, controlar o fluxo da aplicação e conectar as regras de negócio aos modelos e às visualizações.

A utilização desse padrão contribui para a organização do código, separação de responsabilidades e manutenção do sistema.
